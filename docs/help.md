`ali help`
==========

Display help for ali.

* [`ali help [COMMAND]`](#ali-help-command)

## `ali help [COMMAND]`

Display help for ali.

```
USAGE
  $ ali help [COMMAND...] [-n]

ARGUMENTS
  [COMMAND...]  Command to show help for.

FLAGS
  -n, --nested-commands  Include all nested commands in the output.

DESCRIPTION
  Display help for ali.
```
